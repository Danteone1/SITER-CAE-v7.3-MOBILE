# SUBIR DESDE ANDROID

## Opción recomendada

1. Descarga y descomprime el ZIP.
2. Entra en GitHub desde Chrome.
3. Crea un repositorio vacío llamado `SITER-CAE-v7.3-MOBILE`.
4. Abre **Add file → Upload files**.
5. Selecciona todos los archivos y la carpeta `netlogo/` del proyecto.
6. Haz Commit changes.

La raíz de GitHub debe mostrar:

```text
streamlit_app.py
siter_engine.py
requirements.txt
netlogo/
```

## Si GitHub móvil no acepta una carpeta

Crea el archivo mediante **Add file → Create new file** usando el nombre:

`netlogo/territorial_lab_mobile.nlogo`

La ruta con `/` hace que GitHub cree la subcarpeta.
